ZUMBI BOT

Manual de instalação local

Como baixar o Zumbi Bot e rodar no seu computador. São uns 5 minutos: instalar duas ferramentas, copiar quatro comandos e abrir o jogo no navegador.

Jogar agora no navegador Código no GitHub

1Quer só jogar?

Não precisa instalar nada: o jogo roda direto em marcelojaloto.github.io/Zumbi-Bot, no computador, no celular ou no tablet. Esta página é para quem quer rodar o jogo na própria máquina (para testar, estudar ou mexer no código).

No celular: deite o aparelho. Os controles de toque aparecem sozinhos — direcional à esquerda e botões à direita. Para jogar em tela cheia, use "Adicionar à tela inicial" no menu do navegador e abra pelo ícone.

2O que você precisa

Node.js 22 LTSVersão mínima 20.19 (exigida pelo Vite 8).
GitPara baixar o código.
Navegador com WebGLChrome, Edge, Firefox ou Safari atualizados.

3Instalar as ferramentas

  1. Baixe e instale o Node.js 22 LTS em nodejs.org (instalador .msi; pode aceitar as opções padrão).
  2. Baixe e instale o Git for Windows em git-scm.com.
  3. Feche e abra de novo o PowerShell (menu Iniciar → "PowerShell") para ele enxergar os programas.
  1. Baixe e instale o Node.js 22 LTS em nodejs.org (instalador .pkg). Quem usa Homebrew pode rodar brew install node git.
  2. O Git costuma vir com o macOS: se o Terminal pedir as "ferramentas de linha de comando" na primeira vez, aceite a instalação.
  3. Abra o Terminal (Spotlight → "Terminal").
  1. Instale o Git pelo gerenciador da sua distribuição, por exemplo sudo apt install git (Debian/Ubuntu) ou sudo dnf install git (Fedora).
  2. Instale o Node.js 22 seguindo nodejs.org/en/download (recomendado: pelo gerenciador de versões nvm). O Node dos repositórios antigos costuma ser velho demais.
  3. Abra um terminal.

Confira se deu certo (o Node deve mostrar v22, ou pelo menos v20.19):

node --version
git --version

4Baixar e rodar o jogo

No terminal, copie e rode estes comandos, um de cada vez:

git clone https://github.com/marcelojaloto/Zumbi-Bot.git
cd Zumbi-Bot
npm install
npm run dev

Quando aparecer Local: http://localhost:5173/Zumbi-Bot/, abra esse endereço no navegador: http://localhost:5173/Zumbi-Bot/

Deixe o terminal aberto enquanto joga: ele é o servidor do jogo. Para parar, volte ao terminal e aperte Ctrl + C. Da próxima vez, basta entrar na pasta (cd Zumbi-Bot) e rodar npm run dev de novo.

Jogar no celular pela mesma rede Wi-Fi

Rode com --host e abra no celular o endereço "Network" que aparecer no terminal (algo como http://192.168.0.10:5173/Zumbi-Bot/): 

npm run dev -- --host

Versão de produção (igual à do site)

npm run build
npm run preview

Depois abra http://localhost:4173/Zumbi-Bot/.

Atualizar para a versão mais nova

cd Zumbi-Bot
git pull
npm install

5Atalhos para testar

Acrescente ao endereço do jogo (por exemplo http://localhost:5173/Zumbi-Bot/?map=arena&god=1):

?map=vila Abre direto um mapa: vila, torre, banco, castelo, toxica, floresta, centro, chamas, guerra, arena.
&god=1 Modo invencível.
&quality=low Força a qualidade gráfica: low, medium ou high.
&debug=1 Ferramentas de teste; F1–F8 criam inimigos na hora.
&mute=1 Sem som.

6Problemas comuns

"node", "npm" ou "git" não é reconhecido como comando
O programa não foi instalado ou o terminal foi aberto antes da instalação. Instale e abra um terminal novo.
Erro de versão do Node ao rodar npm run dev
Seu Node é antigo. Instale o Node.js 22 LTS e confira com node --version.
"Não é possível acessar esse site" em localhost:5173
O servidor não está rodando: o terminal foi fechado ou o npm run dev parou com erro. Rode npm run dev de novo dentro da pasta Zumbi-Bot. O endereço localhost só funciona no computador onde o comando está rodando.
"Port 5173 is already in use"
Outro servidor já está usando a porta. Feche o outro terminal ou use o endereço com a porta que o Vite sugerir.
Tela preta ou erro de WebGL
Ative a aceleração de hardware do navegador (no Chrome: Configurações → Sistema → "Usar aceleração de gráficos quando disponível") e reinicie o navegador.
Sem som
Os navegadores só liberam o áudio depois do primeiro clique ou toque: clique em "Jogar".

Local installation manual

How to download Zumbi Bot and run it on your computer. It takes about 5 minutes: install two tools, copy four commands and open the game in your browser.

Play now in the browser Code on GitHub

1Just want to play?

No install needed: the game runs at marcelojaloto.github.io/Zumbi-Bot on computers, phones and tablets. This page is for running the game on your own machine (to test it, study it or change the code).

On a phone: turn the device sideways. The touch controls appear on their own — D-pad on the left and buttons on the right. For full screen, use "Add to Home Screen" in the browser menu and open the game from the icon.

2What you need

Node.js 22 LTSMinimum version 20.19 (required by Vite 8).
GitTo download the code.
A WebGL browserUp-to-date Chrome, Edge, Firefox or Safari.

3Install the tools

  1. Download and install Node.js 22 LTS from nodejs.org (.msi installer; the default options are fine).
  2. Download and install Git for Windows from git-scm.com.
  3. Close and reopen PowerShell (Start menu → "PowerShell") so it can find the new programs.
  1. Download and install Node.js 22 LTS from nodejs.org (.pkg installer). Homebrew users can run brew install node git.
  2. Git usually ships with macOS: if Terminal asks to install the "command line developer tools" the first time, accept it.
  3. Open Terminal (Spotlight → "Terminal").
  1. Install Git with your distribution's package manager, for example sudo apt install git (Debian/Ubuntu) or sudo dnf install git (Fedora).
  2. Install Node.js 22 following nodejs.org/en/download (recommended: the nvm version manager). The Node in older repositories is usually too old.
  3. Open a terminal.

Check that it worked (Node should print v22, or at least v20.19):

node --version
git --version

4Download and run the game

In the terminal, copy and run these commands one at a time:

git clone https://github.com/marcelojaloto/Zumbi-Bot.git
cd Zumbi-Bot
npm install
npm run dev

When Local: http://localhost:5173/Zumbi-Bot/ appears, open that address in your browser: http://localhost:5173/Zumbi-Bot/

Keep the terminal open while you play: it is the game's server. To stop it, go back to the terminal and press Ctrl + C. Next time, just go into the folder (cd Zumbi-Bot) and run npm run dev again.

Play on your phone over the same Wi-Fi

Run it with --host and open the "Network" address shown in the terminal on your phone (something like http://192.168.0.10:5173/Zumbi-Bot/): 

npm run dev -- --host

Production build (same as the website)

npm run build
npm run preview

Then open http://localhost:4173/Zumbi-Bot/.

Update to the latest version

cd Zumbi-Bot
git pull
npm install

5Testing shortcuts

Add these to the game address (for example http://localhost:5173/Zumbi-Bot/?map=arena&god=1):

?map=vila Opens a map directly: vila, torre, banco, castelo, toxica, floresta, centro, chamas, guerra, arena.
&god=1 God mode.
&quality=low Forces the graphics quality: low, medium or high.
&debug=1 Testing tools; F1–F8 spawn enemies on the spot.
&mute=1 No sound.

6Common problems

"node", "npm" or "git" is not recognized as a command
The program is not installed, or the terminal was opened before installing it. Install it and open a new terminal.
Node version error when running npm run dev
Your Node is too old. Install Node.js 22 LTS and check with node --version.
"This site can't be reached" at localhost:5173
The server is not running: the terminal was closed or npm run dev stopped with an error. Run npm run dev again inside the Zumbi-Bot folder. The localhost address only works on the computer where the command is running.
"Port 5173 is already in use"
Another server is using the port. Close the other terminal or use the address with the port Vite suggests.
Black screen or WebGL error
Turn on hardware acceleration in your browser (in Chrome: Settings → System → "Use graphics acceleration when available") and restart the browser.
No sound
Browsers only allow audio after the first click or tap: click "Play".
